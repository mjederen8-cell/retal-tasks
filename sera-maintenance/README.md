# سيرا للصيانة — SERA Maintenance

برنامج ويب لطلبات صيانة الشقق السكنية بهوية **سيرا التنفيذية**. يعمل على الجوال والتابلت والكمبيوتر بدون تثبيت.

| الصفحة | لمن | الوظيفة |
|---|---|---|
| `index.html` | العميل (الساكن) | رفع طلب صيانة (الاسم، الجوال، الشقة، نوع الخدمة، الأولوية، الملاحظات) ومتابعة حالته برقم الطلب |
| `admin.html` | فريق الصيانة | عرض كل الطلبات، فلترة وبحث، تغيير الحالة، كتابة رد يظهر للعميل |

قاعدة البيانات: **Google Sheets** (مجانية، وتقدر تفتح الطلبات كجدول Excel مباشرة).

## الخطوة 1 — ربط قاعدة البيانات (5 دقائق)

1. أنشئ Google Sheet جديد باسم "طلبات صيانة سيرا".
2. من القائمة: **Extensions ← Apps Script**.
3. احذف المحتوى والصق محتوى الملف `backend/Code.gs` ثم احفظ.
4. **Deploy ← New deployment** ← النوع **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
5. وافق على الصلاحيات، ثم انسخ رابط **Web app URL** (ينتهي بـ `/exec`).
6. الصقه في `config.js` داخل `API_URL`.

> بدون هذه الخطوة يعمل البرنامج في "وضع التجربة" ويحفظ على نفس الجهاز فقط.

## الخطوة 2 — نشر الرابط

GitHub Pages: **Settings ← Pages ← Deploy from a branch ← main / root**.
الرابط يصبح: `https://<user>.github.io/<repo>/sera-maintenance/`

## ملاحظة أمنية

لوحة الإدارة بدون كلمة مرور (حسب الطلب)، فأي شخص يعرف رابط `admin.html` يرى بيانات العملاء (أسماء وجوالات). لا تشارك رابطها خارج فريق الصيانة.
