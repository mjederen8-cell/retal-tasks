# Retal Tasks 🎀

تطبيق ويب لمتابعة المهام اليومية بطابع أنثوي مرح — بدون أي أدوات بناء، HTML/CSS/JS فقط.

## ✨ المميزات

- **🗓️ صفحة خطتي** (`index.html`): إضافة مهام جديدة وتقسيمها تلقائيًا حسب التاريخ (اليوم، غدًا، الأيام القادمة، الفائتة).
- **🌞 صفحة مهام اليوم** (`today.html`): عرض مهام اليوم مع مؤشر تحفيز متدرج (🐣 → 🦋 → ⭐ → 🔥 → 👑) واحتفال بالقصاصات عند إكمال كل المهام 🎉.
- **⏰ وقت للمهمة** مع تذكير لطيف داخل التطبيق وإشعار من المتصفح عند حلول الموعد.
- **🔁 تكرار المهام**: كل يوم / كل أسبوع / كل شهر — تنتقل المهمة تلقائيًا لموعدها التالي.
- **🎵 أصوات تحفيزية** مولّدة داخل المتصفح عند إنجاز المهام.
- **💾 حفظ تلقائي** في المتصفح (localStorage) — لا يحتاج خادمًا ولا حسابًا.

## 🚀 التشغيل

افتحي `index.html` مباشرة في المتصفح، أو شغّلي سيرفرًا محليًا:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
# ثم افتحي http://localhost:8090
```

صُنع بحب لريتال 💗
